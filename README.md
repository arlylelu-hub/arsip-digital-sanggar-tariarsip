## 4. Estimasi Total Storage + Cadangan 30%

Langkah 1: Total storage awal

36.185 MB ÷ 1.000 = 36,185 GB

Langkah 2: Menghitung cadangan 30%

30% × 36,185 GB = 10,8555 GB

Langkah 3: Menghitung total storage

Total storage = storage awal + cadangan

36,185 GB + 10,8555 GB = 47,0405 GB

Jadi, hasil estimasi kebutuhan penyimpanan adalah:

- Total data awal: 36,19 GB
- Cadangan 30%: 10,86 GB
- Total storage: 47,04 GB
- Rekomendasi kapasitas penyimpanan: 64 GB

## 5. Kesimpulan

Arsip digital sanggar tari membutuhkan delapan jenis data utama yang terdiri dari data anggota, materi tari, foto, video, administrasi, kegiatan, musik, serta kostum dan properti. Berdasarkan asumsi jumlah data selama satu tahun, total kebutuhan penyimpanan diperkirakan sebesar 36,19 GB. Setelah ditambah cadangan 30%, kebutuhan menjadi 47,04 GB. Oleh karena itu, media penyimpanan berkapasitas minimal 64 GB direkomendasikan untuk kebutuhan awal arsip digital sanggar tari.
